PERTEMUAN_11 — E-Commerce Shopshop

Isi:
- index.html: struktur halaman website.
- style.css: tampilan dan tata letak.
- img/: ilustrasi lokal untuk gambar produk.

Menjalankan:
1. Ekstrak PERTEMUAN_11.zip.
2. Buka folder PERTEMUAN_11 di Visual Studio Code.
3. Klik index.html dan buka melalui browser, atau gunakan Live Server.

VS Code dan browser sudah cukup. XAMPP tidak diperlukan karena proyek menggunakan HTML dan CSS statis.

Catatan: beberapa bagian foto kurang terbaca, sehingga kode ini merupakan rekonstruksi dari bagian yang terlihat, bukan jaminan salinan karakter demi karakter. Gambar produk lokal adalah ilustrasi pengganti karena gambar asli dosen tidak disertakan.
